# iNaturalist

Datos de iNaturalist.org. Dataset masivo (~800 MB).

## Columnas principales
- scientificName
- countryCode
- stateProvince
- decimalLatitude / decimalLongitude
- eventDate
- recordedBy
- taxon fields (kingdom, phylum, class, order, family, genus, species)

## Notas
- ~90% de registros con coordenadas
- Dataset grande: los endpoints leen máximo 2000 filas
